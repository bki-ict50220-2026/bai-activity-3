# Creating Objects

There are a few common ways to create an object.

## 1. Object Literal (Most Common)

```javascript
const car = {
  brand: "Toyota",
  model: "Corolla",
  year: 2020
};
```

## 2. Using `new Object()`

```javascript
const car = new Object();
car.brand = "Toyota";
car.model = "Corolla";
car.year = 2020;
```

## 3. Empty Object

```javascript
const empty = {};
```
