# What is JSON?

**JSON** stands for **JavaScript Object Notation**. It is a text format used to store and share data. It looks a lot like a JavaScript object, but it is actually a **string** (plain text).

JSON is commonly used to send data between a web browser and a server.

## Example JSON

```json
{
  "name": "Alice",
  "age": 30,
  "isStudent": false,
  "hobbies": ["reading", "coding", "hiking"]
}
```

## JSON Rules

1. **Keys must be in double quotes** (`"name"` not `name`).
2. **Strings must be in double quotes** (no single quotes).
3. No trailing commas.
4. No comments.
5. No functions or methods — only data.
