# What is an Object?

An **object** is a collection of related data stored as **key-value pairs**. Think of it like a box with labeled compartments, where each label (the *key*) tells you what is inside that compartment (the *value*).

Each key-value pair is called a **property**.

```javascript
const person = {
  name: "Alice",
  age: 30,
  isStudent: false
};
```

In this example:

- `name`, `age`, and `isStudent` are the **keys** (also called properties).
- `"Alice"`, `30`, and `false` are the **values**.
